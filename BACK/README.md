# Backend: первая версия сообществ

Из папки `BACK` установить зависимости и запустить сервер:

```sh
python3 -m uv sync --locked
.venv/bin/python -m uvicorn main:app --reload
```

Требуются Python 3.11+ и uv. Документация запросов: http://127.0.0.1:8000/docs.

- `POST /communities`: тело `{"name": "Новая группа", "description": "Описание"}`; описание необязательно. Ответ — 201 с данными группы.
- `GET /communities/{community_id}`: ответ — 200 с данными группы или 404, если группы нет.
- Пустое название, название из пробелов или длиннее 100 символов отклоняется с 422; описание ограничено 1000 символами.

Пока это учебная версия: хранилище — словарь в памяти одного процесса. Созданные группы исчезают после перезапуска, в том числе автоматического перезапуска при изменении кода. Одновременное создание запросами не защищено от совпадения ID; несколько процессов не разделяют данные. Владелец и число участников временно равны 1, авторизация и вступление ещё не подключены. Эти обработчики предназначены для локальной проверки до перехода на общие модели SQLite.
