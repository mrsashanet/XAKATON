Backend: сообщества

Установка и запуск из папки BACK:

python3 -m uv sync --locked
.venv/bin/python -m uvicorn main:app --reload

Документация API: http://127.0.0.1:8000/docs

POST /communities — создание. Тело: {"name": "Новая группа"}. Возвращает данные группы и invite_token.

POST /communities/join — вступление. Тело: {"invite_token": "код из ответа создания"}. Повторное вступление не добавляет участника повторно.

GET /communities/{community_id} — информация для участника. Постороннему возвращается 403, неизвестная группа — 404.

Данные сохраняются в SQLite BACK/app.db. Запускать сервер нужно из BACK. Уникальный индекс uq_membership_user_community запрещает повторное членство.

Запросы сообществ требуют заголовок Authorization: Bearer <access_token>. Пользователь определяется через общую зависимость auth.dependencies.get_current_user. Без корректного токена возвращается 401. Регистрация и вход должны быть подключены модулем авторизации.

Для базы, созданной до добавления уникального индекса, его нужно применить отдельно. create_all() не обновляет существующую схему.

## Загрузка и прослушивание MP3

Аудио хранится в `BACK/media/tracks`; каталог создаётся автоматически. `TRACKS_DIRECTORY` может задать другую папку. В обычной папке уже есть оригинальный демотрек `Universe Voicee - First Light.mp3`, который можно выбрать в интерфейсе. Файлы, загруженные через API, получают случайные имена.

- `POST /tracks/upload`: multipart-поля `title`, `artist`, `community_id`, `file`; возвращает TrackOut, код 201. Нужен JWT участника сообщества.
- `POST /tracks/{track_id}/audio`: multipart-поле `file`; прикрепляет MP3 к старой записи без аудио. Доступен автору трека или владельцу сообщества; повторное прикрепление даёт 409.
- `GET /tracks/{track_id}/audio`: MP3 для авторизованного участника; поддерживает Range (206). Папка не публикуется через StaticFiles.

Лимит одного файла — 30 МБ. Расширение и MPEG Layer III проверяются через mutagen. Повреждённый/неподходящий файл даёт 415, превышение лимита — 413. При сбое записи в БД файл удаляется. Существующий `POST /tracks` с JSON продолжает работать, модели и таблицы не менялись. Чтобы слушать трек, MP3 нужно загрузить через форму; файлы в папке автоматически не импортируются.

Новая зависимость указана в pyproject.toml/uv.lock; установка обычной командой `python3 -m uv sync --locked` из BACK. Аудиотесты запускаются из BACK: `.venv/bin/python tests/test_audio.py -v`. Они используют отдельную SQLite и временную папку, рабочие данные не меняют.
