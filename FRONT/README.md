# Universe Voicee

Общий плейлист для друзей и одногруппников. Тёмный графитовый интерфейс с зелёным акцентом; на странице сообщества главное место занимает список треков.

## Запуск

Нужен Node.js 20+. Обязательных npm-зависимостей нет. Сначала запустите существующий backend из BACK по его инструкции, затем из FRONT:

```sh
npm run dev
```

Откройте http://localhost:5173. Сервер перенаправляет `/api/*` на `http://127.0.0.1:8000`. Другой адрес backend задаётся при запуске:

```sh
API_TARGET=http://192.168.1.20:8000 npm run dev
```

Для доступа с другого устройства: `npm run dev -- --host 0.0.0.0`, затем откройте сетевой адрес компьютера. Для публичного размещения нужен серверный reverse proxy `/api`; текущий dev-сервер предназначен для разработки.

## Возможности

Регистрация и вход, восстановление сессии вкладки, создание сообществ, вступление по приглашению, копирование ссылки, добавление треков, поиск, сортировка, голоса +1/-1 и отмена. Пустые состояния и ошибки, мобильная версия, управление с клавиатуры. Музыкальные рекомендации используют настоящее API; демонстрационные записи автоматически не добавляются. Добавление треков включает загрузку настоящего MP3 до 30 МБ. Плеер поддерживает паузу, перемотку, громкость, предыдущий/следующий трек и продолжает работу при переходах внутри приложения. К старой записи без файла автор или владелец сообщества может прикрепить MP3.

## Совместимость с командой

Проверено с опубликованным `main` 64fa8d0, включая GET `/auth/me`, добавленный командой. В рамках этого редизайна BACK не изменялся. API-клиент Артёма сохранён; адаптер `src/workspace.js` учитывает доступные маршруты из OpenAPI.

В опубликованном API пока нет GET списка сообществ и повторного получения приглашения; рейтинг не содержит личный голос. Поэтому:

- ID открытых сообществ запоминаются в localStorage отдельно для каждого аккаунта. Названия, число участников и доступ заново проверяются сервером. На другом устройстве откройте исходное приглашение или прямую ссылку на уже доступное сообщество.
- Приглашения от создания или вступления сохраняются в sessionStorage вкладки. После её закрытия для повторной отправки понадобится исходное приглашение. Токен приглашения не сохраняется в localStorage.
- Выбранные голоса запоминаются в этом браузере; суммарный рейтинг всегда приходит с сервера. Подсветка своего голоса может отличаться на другом устройстве.

Если сервер предоставляет GET `/communities`, GET `/communities/{id}/invitation` или поле `my_vote`, фронт автоматически использует их. Это не требование вносить изменения в backend.

JWT находится в sessionStorage, удаляется при выходе/401. Пароли не сохраняются. Перед публичным запуском SECRET_KEY backend должен быть задан командой через окружение.

## Проверки и сборка

```sh
npm test
npm run check
npm run build
npm run preview
```

`npm test` запускает тесты клиента и адаптера. Полный HTTP-сценарий запускается только с `TEST_API_URL`, указывающим на отдельный тестовый backend, и создаёт тестовые аккаунты:

```sh
TEST_API_URL=http://127.0.0.1:8001 npm test
```

Проверяются два пользователя, регистрация/вход/выход, доступ к группам, приглашение и повторное вступление, треки, положительный/отрицательный голос и отмена. `build` создаёт игнорируемую Git папку `dist/`; `preview` также перенаправляет `/api` на backend.


## MP3 и плеер

Файлы находятся в `BACK/media/tracks`. Пример `Universe Voicee - First Light.mp3` — оригинальный короткий инструментальный демотрек; его можно выбрать в форме загрузки. Простое копирование MP3 в папку не добавляет запись в плейлист: используйте «Добавить трек» в интерфейсе.

Нужен backend с POST `/tracks/upload`, POST/GET `/tracks/{id}/audio` и полями `file_url`, `added_by` в плейлисте. Прежний JSON POST `/tracks` сохранён. Структура таблиц не меняется: используется существующее `Track.file_url`.

Перед воспроизведением фронт получает файл с JWT в заголовке Authorization и создаёт временный Blob URL. Основной JWT не попадает в адрес аудио. В этом MVP каждый MP3 сначала скачивается целиком (до 30 МБ); перемотка затем работает по загруженному файлу. При переключении трека или выходе Blob URL освобождается. Сервер также поддерживает HTTP Range; доступ к MP3 проверяется по членству в сообществе.
